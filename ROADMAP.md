# Roadmap

This roadmap orders open work by leverage and dependency. Each item links to a GitHub issue with full details. Checkboxes are updated automatically when issues are closed or reopened.

## Phase 1: Foundation

- [ ] Next.js 15 project scaffolding with Tailwind v4 and TypeScript
- [ ] Layout, navigation, and dark mode toggle
- [ ] Design system tokens and base components

## Phase 2: Core Sections

- [ ] Hero section with bio and social links
- [ ] Project showcase grid with GitHub API integration
- [ ] Contact section with email link and socials

## Phase 3: Blog

- [ ] MDX blog infrastructure with syntax highlighting
- [ ] Blog listing page and individual post pages
- [ ] RSS feed generation

## Phase 4: Polish & Deploy

- [ ] SEO, meta tags, and Open Graph images
- [ ] Animations and scroll effects
- [ ] Vercel deployment and performance optimization
